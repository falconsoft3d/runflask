Despliega tus proyectos Flask con un solo push

RunFlask es una plataforma inspirada en Vercel: conecta un repositorio de GitHub o sube una carpeta local, y obtén tu proyecto Flask corriendo en Docker con su propio subdominio, sin configurar servidores a mano.

Conecta GitHub

Autoriza tu cuenta, elige un repositorio y cada git push dispara un nuevo deploy automatico via webhook.

O sube una carpeta local

¿No usas GitHub todavia? Comprime tu proyecto en un .zip y súbelo directamente desde el panel.

Un subdominio propio

Cada proyecto corre en su propio contenedor Docker aislado y queda disponible en tu-proyecto.localhost.

Cómo colaborar

RunFlask es un proyecto abierto y en evolución. Si quieres contribuir:

  • Reporta errores o ideas abriendo un issue en el repositorio.
  • Envía un pull request con mejoras, correcciones o nuevas funciones.
  • Ayuda a mejorar la documentación del README.md.
  • Comparte feedback sobre tu experiencia usando la plataforma.
